# Codificador Universal

Ferramenta Python para codificar e descodificar texto usando diferentes representações.

## Funcionalidades

- Hexadecimal
- Binário
- Octal
- Decimal
- Base64
- Exportação/impressão em JSON

## Requisitos

Python 3.8 ou superior.

## Linux / macOS

```bash
python3 codificador.py
